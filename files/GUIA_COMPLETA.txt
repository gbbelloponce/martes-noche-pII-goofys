EJEMPLOS DE USO:
================

EJEMPLO 1: Crear un ABB simple
──────────────────────────────

```java
import ABB.*;

public class Ejemplo1 {
    public static void main(String[] args) {
        // Crear el árbol
        ABBEnteros abb = new ABBEnterosImpl();
        
        // Agregar elementos
        int[] valores = {50, 30, 70, 20, 40, 60, 80};
        for (int v : valores) {
            abb.agregar(v);
        }
        
        // Búsquedas
        System.out.println("¿Contiene 40? " + abb.contiene(40)); // true
        System.out.println("¿Contiene 99? " + abb.contiene(99)); // false
        
        // Estadísticas
        System.out.println("Cantidad: " + abb.cantidad());       // 7
        System.out.println("Altura: " + abb.altura());          // 3
        System.out.println("Mínimo: " + abb.minimo());          // 20
        System.out.println("Máximo: " + abb.maximo());          // 80
        
        // Recorridos
        System.out.print("Inorden: ");
        abb.mostrarInOrden();  // 20 30 40 50 60 70 80
        
        // Eliminar
        abb.eliminar(40);
        System.out.println("Después de eliminar 40:");
        abb.mostrarInOrden();  // 20 30 50 60 70 80
    }
}
```

```java
import ABB.*;

public class Ejemplo2 {
    public static void main(String[] args) {
        ABBEnterosImpl abb = new ABBEnterosImpl();

        for (int i = 1; i <= 10; i++) {

        System.out.println("¿En rango [0, 20]? " + abb.enRango(0, 20));   // true
    }
}
```

EJEMPLO 4: Operaciones con conjunto
────────────────────────────────────

```java
import ABB.*;

public class Ejemplo4 {
    public static void main(String[] args) {
        // Crear conjuntos
        ConjuntoABB a = new ConjuntoABB();
        ConjuntoABB b = new ConjuntoABB();
        
        // Elementos de A: {1, 2, 3, 4, 5}
        for (int i = 1; i <= 5; i++) a.agregar(i);
        
        // Elementos de B: {3, 4, 5, 6, 7}
        for (int i = 3; i <= 7; i++) b.agregar(i);
        
        System.out.println("Conjunto A: " + a.toString());  // {1, 2, 3, 4, 5}
        System.out.println("Conjunto B: " + b.toString());  // {3, 4, 5, 6, 7}
        
        // Intersección
        ConjuntoABB c = a.interseccion(b);
        System.out.println("A ∩ B: " + c.toString());        // {3, 4, 5}
        
        // Operaciones
        a.eliminar(2);
        System.out.println("Después de eliminar 2 de A: " + a.toString());
        System.out.println("¿A contiene 3? " + a.contiene(3));
    }
}
```

NOTAS IMPORTANTES:
==================

1. RECURSIÓN vs ITERACIÓN:
   - agregarRecursivo() es la implementación del Ejercicio 1
   - agregarIterativo() es la solución al Ejercicio 2
   - Ambas están implementadas en ABBEnterosImpl

2. COMPLEJIDAD:
   - Todos los análisis están incluidos en los comentarios del código
   - Ver también EJERCICIO_3_5_7_ANALISIS.txt para detalles

3. TESTS:
   - ABBEnterosTest.java contiene 11 tests que validan toda la funcionalidad
   - Todos deben pasar sin errores

4. PARTICULARIDADES:
   - Inorden imprime los valores en ORDEN ASCENDENTE (propiedad del ABB)
   - No se permiten duplicados (se valida en agregar)
   - minimo() y maximo() lanzan IllegalStateException si el árbol está vacío

5. CONSIDERACIONES DE DISEÑO:
   - Se usa recursión en la mayoría de métodos (como se especifica)
   - Se implementó agregarIterativo() como alternativa (Ejercicio 2)
   - Los recorridos mantienen el orden esperado

6. EXTENSIONES FUTURAS:
   - Para árboles muy grandes, considerar AVL o Árbol Rojo-Negro
   - Para búsquedas frecuentes en datos estáticos, considerar búsqueda binaria
   - Para aplicaciones de producción, validar entrada y manejar más excepciones


TROUBLESHOOTING:
================

Problema: "No se encuentra la clase ABBEnteros"
Solución: Verificar que todos los .java estén en el directorio ABB/
          Compilar con: javac ABB/*.java

Problema: StackOverflowError al ejecutar TestRecursividadABB
Solución: Esto es NORMAL si usa agregarRecursivo()
          Usar agregarIterativo() para evitarlo
          Ver EJERCICIO_2_ANALISIS.txt para detalles

Problema: IndiceABB no encuentra Texto.txt
Solución: Asegurar que Texto.txt esté en el directorio raíz del proyecto
          O pasar la ruta correcta al método procesarArchivo()

Problema: Tests no compilan
Solución: Verificar que las clases estén en el paquete ABB
          Que el archivo comience con: package ABB;

Problema: Errores de import
Solución: Todas las clases están en el paquete ABB
          Los imports deben ser: import ABB.*;
